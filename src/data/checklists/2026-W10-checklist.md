## 📝 이번 주 뉴스 요약
**AI 에이전트 시대, CLI가 부활하다**
1960년대부터 사용되어온 CLI(명령줄 인터페이스)가 AI 에이전트 시대에 다시 주목받고 있습니다. GUI 중심의 소프트웨어 패러다임에서 AI 에이전트가 소프트웨어를 사용하는 주체로 부상하면서, 인간 중심의 GUI보다 AI가 더 효율적으로 작동할 수 있는 CLI의 중요성이 증대되었습니다. Obsidian, Google Workspace(gogcli, gws), Microsoft 365(mogcli), Vercel(agent-browser) 등 주요 서비스들이 에이전트 친화적 CLI를 공개하고 있으며, 기존의 복잡한 MCP 프로토콜 대신 단순하고 강력한 CLI 기반 통합이 더 실용적임이 입증되고 있습니다. 에이전트용 CLI는 JSON 입력, 구조화된 출력, 기계 판독 가능한 스키마, 입력 검증 등 인간 중심 CLI와는 근본적으로 다른 설계 철학이 필요합니다. 이제 모든 SaaS 서비스들도 에이전트 시대를 대비해 CLI 제공을 고민해야 할 시점입니다.
